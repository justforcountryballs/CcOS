The desktop backgrounds (rootfs/usr/share/ccos/wallpapers) are drawn by these
scripts from scratch, so they belong to ccos and can be shared freely.
  python3 water.py 1920 1080 water.png      (also surreal, lake, slabs,
  python3 lake.py 1920 1080 snowy-lake.png snow   sparkle, clouds)
Needs numpy, scipy and Pillow.
